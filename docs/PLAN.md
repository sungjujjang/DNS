# 개요
API.md에 있는 것들을 가지고, DMS-Discord 봇을 만들어라. 이름은 DNS로!

# 핵심 구현
- 모든 명령어는 슬래시 커맨드로 구현할 것
- 아이디/비밀번호를 저장할 것. (개인정보 동의는 모두 맡은 상태)
- 매 요청마다 새로 로그인해도 되고, Access Token 저장해놓고 만료되면 새로 로그인 또는 refresh token으로 재검증? 해도 될 듯
- RTR 사용중인지 잘 모르니까, 그리고 Refresh는 어디서 하는지 잘 모르니까 너가 잘 살펴볼 것
- 만일 모든 것을 확인했다면, 다음 구조로 진행할 것
    1. Access Token을 저장해놨다가 사용자 슬래시 커맨드 사용시 사용
    2. 만료되었으면, Refresh Token 이용해 다시 발급받을 것
    3. Refresh Token까지 만료되었으면, ID/PW 통해 다 새로 발급받을 것
- 사용자(디스코드) - 유저(dms) 는 1:1 관계
- 사용자는 로그인 시 모달 창을 이용해 로그인 할 수 있게 할 것
- 모든 출력은 임베드를 이용해 이쁘게 출력할 것 (AI 티 안나게)

# 기능

## 로그인 기능
- 모달 창을 이용해 로그인
- 로그인 시 아이디 비밀번호를 검증할 것

## 내정보 확인 기능
- 내정보 명령어를 통해, 상벌점, 학번, 프로필 사진 등을 볼 수 있게 할 것

## 새자 신청 양식 미리 저장
- 새자 신청 양식을 저장할 수 있게 할 것
- 날짜는 그 주의 무슨 요일부터 무슨 요일까지 선택할 수 있게 하되, 월/목요일 사이에 할 수있게 할 것.
- 선생님 선택은 드롭다운으로 해서 안 타이핑해도 되게 할 것

## 새자 신청
- 양식 중 하나를 골라 신청할 수 있게 할 것

## 새자 신청 자동화
- 양식 중 하나를 골라, 무슨 요일 몇시에 자동으로 신청되게 할 것
- API 응답 결과를 통해, 신청이 잘 되었으면 개인 디엠으로 보내고, 안되었으면 실패 메시지도 이유와 함께 보낼 것

## 새자 상태 확인
- 내 새자 신청 상태를 확인할 수 있게 할 것

## 급식표 확인
- 대덕소프트웨어마이스터고등학교의 급식표를 확인할 수 있게 할 것
- 아침, 점심, 저녁 3개 다 확인 가능하게 할 것

## 급식표 알림 설정
- 급식표 알림 받아보기를 하면, 매일 지정한 시간에 급식표가 디엠으로 3식 다 오게 할 것

## 화이트리스트 온 오프 (관리자)
- 지정한 사람들만 봇을 사용할 수 있게 화이트리스트 온 오프 기능을 만들 것

## 화이트리스트 추가 삭제 (관리자)
- 화이트리스트에 디스코드 사용자 추가 삭제 할 것

## 관리자 추가 삭제 (관리자)
- 관리자 추가 삭제를 구현할 것
- 삭제는 관리자라도 못하고, 마스터 관리자만 삭제가 가능하게 할 것
